
# LabGit-Settings

## Назначение проекта
Изучение работы GitHub, организации структуры проекта,
настройки правил исключения и обработки файлов.

## Структура каталогов
- src — исходный код C#.
- docs — документация.
- tests — тестовые материалы.
- assets — вспомогательные материалы.

## Настройки репозитория
.gitignore содержит правила исключения временных файлов,
каталогов сборки, журналов и локальных настроек.

.gitattributes задаёт правила обработки текстовых файлов
и бинарных данных, а также окончания строк.

## Вывод
Настройка GitHub помогает поддерживать порядок в проекте,
отделять исходный код от временных данных и управлять
историей изменений с помощью коммитов.
